## Deploy
1. Supabase: Run supabase/schema.sql
2. Netlify: Import from Git, env: VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, SUPABASE_SERVICE_KEY
3. Git push = Auto Deploy
